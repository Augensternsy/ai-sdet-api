# 算法题型知识库

本文档包含常见算法题型的解题模板和思路总结，用于 RAG 检索增强生成。

---

## 1. 数组与哈希表

### 题型特点
- 涉及数组元素的查找、统计、去重
- 需要快速判断元素是否存在或统计出现次数
- 常见问题：两数之和、三数之和、数组去重、元素统计

### 常见关键词
- 数组、查找、统计、出现次数、重复、唯一
- 两数之和、三数之和、四数之和
- 存在、包含、缺失

### 适用场景
- 需要在 O(1) 时间内查找元素
- 需要统计元素出现频率
- 需要判断元素是否重复
- 需要快速定位元素位置

### 核心思路
1. 使用哈希表存储元素值到下标或出现次数的映射
2. 遍历数组时，利用哈希表快速查找目标元素
3. 对于统计类问题，先遍历统计，再处理结果

### 常用数据结构
- 哈希表（字典）：存储值到下标或次数的映射
- 集合：快速去重和判断存在性
- 计数器：统计元素出现频率

### 复杂度规律
- 时间复杂度：O(n)，遍历数组一次
- 空间复杂度：O(n)，最坏情况存储所有元素

### 典型题目
- LeetCode 1: 两数之和
- LeetCode 15: 三数之和
- LeetCode 136: 只出现一次的数字
- LeetCode 349: 两个数组的交集

### 易错点
- 先将元素加入哈希表再查找，可能导致同一元素被使用两次
- 没有考虑数组中有重复元素的情况
- 三数之和问题中，去重逻辑容易遗漏

## 2. 双指针

### 题型特点
- 数组或链表中的元素配对、查找
- 需要从两端向中间或从中间向两端处理
- 常见问题：两数之和（有序数组）、反转数组、回文判断

### 常见关键词
- 有序数组、两端、配对、反转
- 左右指针、快慢指针
- 原地修改、O(1) 空间

### 适用场景
- 有序数组的查找问题
- 需要原地修改数组
- 链表的环检测、中点查找
- 回文字符串判断

### 核心思路
1. 左右指针：初始化在数组两端，根据条件移动指针
2. 快慢指针：快指针每次走两步，慢指针每次走一步
3. 利用指针移动减少不必要的遍历

### 常用数据结构
- 数组：左右指针从两端移动
- 链表：快慢指针检测环或找中点

### 复杂度规律
- 时间复杂度：O(n)，每个元素最多被访问一次
- 空间复杂度：O(1)，只需要常数空间

### 典型题目
- LeetCode 167: 两数之和 II（有序数组）
- LeetCode 15: 三数之和
- LeetCode 42: 接雨水
- LeetCode 141: 环形链表

### 易错点
- 指针移动条件判断错误
- 边界条件处理不当（空数组、单元素）
- 快慢指针初始化位置错误

## 3. 滑动窗口

### 题型特点
- 连续子数组或子字符串问题
- 需要找到满足条件的最长/最短子数组
- 常见问题：最长无重复子串、最小覆盖子串

### 常见关键词
- 子数组、子串、连续
- 最长、最短、满足条件
- 窗口大小、窗口内元素

### 适用场景
- 查找满足条件的连续子数组
- 统计窗口内的元素特征
- 字符串匹配问题

### 核心思路
1. 使用双指针维护窗口边界
2. 右指针扩展窗口，左指针收缩窗口
3. 根据条件判断何时收缩窗口
4. 记录满足条件的最优解

### 常用数据结构
- 哈希表：统计窗口内元素频率
- 双指针：维护窗口边界

### 复杂度规律
- 时间复杂度：O(n)，每个元素最多被访问两次
- 空间复杂度：O(k)，k 为窗口内不同元素数量

### 典型题目
- LeetCode 3: 无重复字符的最长子串
- LeetCode 76: 最小覆盖子串
- LeetCode 209: 长度最小的子数组
- LeetCode 438: 找到字符串中所有字母异位词

### 易错点
- 窗口收缩条件判断错误
- 更新最优解的时机不对
- 没有正确处理窗口内元素计数

## 4. 栈与单调栈

### 题型特点
- 涉及括号匹配、表达式计算
- 需要找到下一个更大/更小元素
- 常见问题：有效括号、每日温度、柱状图最大面积

### 常见关键词
- 括号匹配、表达式求值
- 下一个更大元素、下一个更小元素
- 单调递增、单调递减

### 适用场景
- 括号匹配问题
- 寻找下一个更大/更小元素
- 计算柱状图面积
- 表达式计算

### 核心思路
1. 普通栈：后进先出，用于匹配和计算
2. 单调栈：维护单调递增或递减序列
3. 弹出栈顶时处理相关计算

### 常用数据结构
- 栈：存储待处理的元素或下标
- 单调栈：维护单调性的栈

### 复杂度规律
- 时间复杂度：O(n)，每个元素最多入栈出栈一次
- 空间复杂度：O(n)，最坏情况存储所有元素

### 典型题目
- LeetCode 20: 有效的括号
- LeetCode 739: 每日温度
- LeetCode 84: 柱状图中最大的矩形
- LeetCode 42: 接雨水

### 易错点
- 单调栈的递增/递减方向选择错误
- 弹出元素时的计算逻辑错误
- 边界条件处理（栈为空时）

---

## 5. 队列与优先队列

### 题型特点
- 层次遍历、广度优先搜索
- 需要按优先级处理元素
- 常见问题：二叉树层序遍历、Top K 问题、滑动窗口最大值

### 常见关键词
- 层序遍历、BFS
- 优先级、最大值、最小值
- Top K、前 K 个

### 适用场景
- 二叉树层序遍历
- 图的最短路径（无权图）
- Top K 问题
- 滑动窗口最值

### 核心思路
1. 普通队列：先进先出，用于 BFS
2. 优先队列（堆）：按优先级弹出元素
3. 利用堆的性质维护 Top K

### 常用数据结构
- 队列：BFS 遍历
- 优先队列（堆）：维护最值或 Top K

### 复杂度规律
- 队列操作：O(1)
- 堆操作：插入和删除 O(log n)
- Top K：O(n log k)

### 典型题目
- LeetCode 102: 二叉树的层序遍历
- LeetCode 215: 数组中的第 K 个最大元素
- LeetCode 239: 滑动窗口最大值
- LeetCode 347: 前 K 个高频元素

### 易错点
- 堆的大小控制不当
- 优先队列的比较器设置错误
- BFS 时没有正确标记访问状态

## 6. 二分查找

### 题型特点
- 有序数组或具有单调性的问题
- 需要在 O(log n) 时间内查找
- 常见问题：查找目标值、查找边界、查找峰值

### 常见关键词
- 有序数组、排序数组
- 查找、搜索、定位
- O(log n) 时间复杂度

### 适用场景
- 有序数组查找
- 查找第一个/最后一个满足条件的位置
- 具有单调性的函数求值
- 旋转排序数组

### 核心思路
1. 确定搜索区间 [left, right]
2. 计算中间位置 mid
3. 根据条件缩小搜索范围
4. 注意边界条件和循环终止条件

### 常用数据结构
- 有序数组
- 具有单调性的数据结构

### 复杂度规律
- 时间复杂度：O(log n)
- 空间复杂度：O(1)

### 典型题目
- LeetCode 704: 二分查找
- LeetCode 33: 搜索旋转排序数组
- LeetCode 34: 在排序数组中查找元素的第一个和最后一个位置
- LeetCode 162: 寻找峰值

### 易错点
- 循环终止条件（left < right 还是 left <= right）
- 区间更新方式（left = mid 还是 left = mid + 1）
- 边界条件处理（空数组、单元素）

## 7. 动态规划

### 题型特点
- 问题可以分解为重叠子问题
- 具有最优子结构
- 常见问题：背包问题、最长公共子序列、最短路径

### 常见关键词
- 最优解、最大值、最小值
- 方案数、路径数
- 子问题、状态转移

### 适用场景
- 求最优解问题
- 计数问题
- 可行性问题
- 具有重叠子问题的问题

### 核心思路
1. 定义状态：dp[i] 表示什么
2. 状态转移方程：dp[i] 如何由之前的状态得到
3. 初始化：边界条件
4. 遍历顺序：确保计算 dp[i] 时所需状态已计算

### 常用数据结构
- 一维数组：一维 DP
- 二维数组：二维 DP
- 滚动数组：空间优化

### 复杂度规律
- 时间复杂度：O(状态数量 × 转移代价)
- 空间复杂度：O(状态数量)，可优化

### 典型题目
- LeetCode 70: 爬楼梯
- LeetCode 322: 零钱兑换
- LeetCode 1143: 最长公共子序列
- LeetCode 300: 最长递增子序列

### 易错点
- 状态定义不清晰
- 状态转移方程遗漏情况
- 初始化不正确
- 遍历顺序错误

---

## 8. 贪心算法

### 题型特点
- 每一步选择局部最优
- 最终达到全局最优
- 常见问题：区间调度、跳跃游戏、分发糖果

### 常见关键词
- 最优解、最大/最小
- 局部最优、全局最优
- 每一步选择

### 适用场景
- 问题具有贪心选择性质
- 局部最优能导致全局最优
- 不需要回溯

### 核心思路
1. 分析问题是否具有贪心选择性质
2. 确定贪心策略
3. 证明贪心策略的正确性
4. 按策略逐步求解

### 常用数据结构
- 排序：按某种顺序处理
- 优先队列：动态选择最优

### 复杂度规律
- 时间复杂度：通常 O(n log n)（排序）
- 空间复杂度：O(1) 或 O(n)

### 典型题目
- LeetCode 55: 跳跃游戏
- LeetCode 45: 跳跃游戏 II
- LeetCode 435: 无重叠区间
- LeetCode 455: 分发饼干

### 易错点
- 贪心策略选择错误
- 没有证明贪心策略的正确性
- 排序标准选择不当

---

## 9. DFS / BFS

### 题型特点
- 图或树的遍历
- 需要探索所有可能路径
- 常见问题：岛屿数量、路径查找、最短路径

### 常见关键词
- 遍历、搜索、探索
- 连通、路径、最短
- 岛屿、迷宫

### 适用场景
- 图的遍历和搜索
- 连通性问题
- 路径查找
- 最短路径（BFS）

### 核心思路
1. DFS：深度优先，递归或栈实现
2. BFS：广度优先，队列实现
3. 标记已访问节点，避免重复访问

### 常用数据结构
- DFS：递归栈或显式栈
- BFS：队列
- 访问标记数组

### 复杂度规律
- 时间复杂度：O(V + E)，V 为顶点数，E 为边数
- 空间复杂度：O(V)，存储访问状态

### 典型题目
- LeetCode 200: 岛屿数量
- LeetCode 130: 被围绕的区域
- LeetCode 127: 单词接龙
- LeetCode 79: 单词搜索

### 易错点
- 没有正确标记访问状态
- DFS 递归深度过大导致栈溢出
- BFS 时没有按层处理

## 10. 图论基础

### 题型特点
- 涉及图的遍历、最短路径、拓扑排序
- 需要处理节点和边的关系
- 常见问题：课程安排、网络延迟时间、最小生成树

### 常见关键词
- 图、节点、边
- 最短路径、拓扑排序
- 连通、环

### 适用场景
- 最短路径问题
- 拓扑排序
- 连通性问题
- 环检测

### 核心思路
1. 图的表示：邻接表或邻接矩阵
2. 最短路径：Dijkstra、Bellman-Ford、Floyd
3. 拓扑排序：Kahn 算法或 DFS
4. 最小生成树：Kruskal 或 Prim

### 常用数据结构
- 邻接表：存储图的边
- 优先队列：Dijkstra 算法
- 并查集：Kruskal 算法

### 复杂度规律
- Dijkstra：O((V + E) log V)
- 拓扑排序：O(V + E)
- 最小生成树：O(E log E)

### 典型题目
- LeetCode 207: 课程表
- LeetCode 210: 课程表 II
- LeetCode 743: 网络延迟时间
- LeetCode 785: 判断二分图

### 易错点
- 图的表示方式选择不当
- 没有处理负权边
- 拓扑排序时没有检测环

---

## 11. 回溯算法

### 题型特点
- 需要枚举所有可能的解
- 可以剪枝优化
- 常见问题：全排列、子集、组合总和

### 常见关键词
- 全排列、子集、组合
- 所有解、所有可能
- 剪枝、回溯

### 适用场景
- 排列组合问题
- 子集问题
- 棋盘问题（N 皇后）
- 路径查找

### 核心思路
1. 定义递归函数和参数
2. 确定终止条件
3. 单层搜索逻辑
4. 处理选择、递归、回溯

### 常用数据结构
- 路径数组：记录当前选择
- 使用标记数组：避免重复选择

### 复杂度规律
- 时间复杂度：O(n! × n) 或 O(2^n × n)
- 空间复杂度：O(n)，递归深度

### 典型题目
- LeetCode 46: 全排列
- LeetCode 78: 子集
- LeetCode 39: 组合总和
- LeetCode 51: N 皇后

### 易错点
- 回溯时没有正确撤销选择
- 剪枝条件判断错误
- 重复解的处理

---

## 12. 前缀和

### 题型特点
- 频繁计算区间和
- 需要优化重复计算
- 常见问题：区域和检索、和为 K 的子数组

### 常见关键词
- 区间和、子数组和
- 连续、前缀
- 频繁查询

### 适用场景
- 多次查询区间和
- 统计满足条件的子数组数量
- 二维矩阵区域和

### 核心思路
1. 预处理前缀和数组
2. 利用前缀和快速计算区间和
3. 区间 [i, j] 的和 = prefix[j+1] - prefix[i]

### 常用数据结构
- 一维前缀和数组
- 二维前缀和数组
- 哈希表：存储前缀和出现次数

### 复杂度规律
- 预处理：O(n)
- 单次查询：O(1)
- 空间复杂度：O(n)

### 典型题目
- LeetCode 303: 区域和检索 - 数组不可变
- LeetCode 560: 和为 K 的子数组
- LeetCode 304: 二维区域和检索 - 矩阵不可变
- LeetCode 974: 和可被 K 整除的子数组

### 易错点
- 前缀和数组长度应为 n+1
- 没有正确处理边界条件
- 二维前缀和公式记忆错误

## 13. 并查集

### 题型特点
- 动态连通性问题
- 需要合并集合和查询连通性
- 常见问题：朋友圈、岛屿数量、冗余连接

### 常见关键词
- 连通、合并、查找
- 集合、分组
- 动态连通

### 适用场景
- 动态连通性问题
- 最小生成树（Kruskal）
- 判断图是否有环
- 集合合并问题

### 核心思路
1. 初始化：每个元素独立成一个集合
2. Find：查找元素所属集合的根
3. Union：合并两个集合
4. 路径压缩和按秩合并优化

### 常用数据结构
- 父节点数组：存储每个节点的父节点
- 秩数组：优化合并操作

### 复杂度规律
- 时间复杂度：接近 O(1)（路径压缩后）
- 空间复杂度：O(n)

### 典型题目
- LeetCode 547: 省份数量
- LeetCode 200: 岛屿数量
- LeetCode 684: 冗余连接
- LeetCode 990: 等式方程的可满足性

### 易错点
- 没有使用路径压缩优化
- Union 时没有按秩合并
- Find 时没有递归压缩路径

## 总结

### 题型选择指南

| 关键词 | 推荐题型 |
|--------|----------|
| 查找、统计、重复 | 数组与哈希表 |
| 两端、配对、有序 | 双指针 |
| 子数组、连续、窗口 | 滑动窗口 |
| 括号、下一个更大 | 栈与单调栈 |
| 层序、Top K、优先级 | 队列与优先队列 |
| 有序、O(log n)、边界 | 二分查找 |
| 最优解、状态转移 | 动态规划 |
| 局部最优、区间调度 | 贪心算法 |
| 遍历、连通、路径 | DFS / BFS |
| 最短路径、拓扑排序 | 图论基础 |
| 全排列、子集、所有解 | 回溯算法 |
| 区间和、频繁查询 | 前缀和 |
| 连通、合并集合 | 并查集 |
